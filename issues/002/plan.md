# issues/002 対応計画

## 対象

アプリ内に「その他」画面を追加し、利用規約・プライバシーポリシー・ライセンス画面へ遷移できるようにする。

## 前提

- 実装前に本計画の承認を得る。
- 実装は TDD で進め、先に失敗する Widget テストを追加する。
- 利用規約とプライバシーポリシーの本文は `issues/002/term_of_service.txt` と `issues/002/privacy_policy.txt` を初稿として使用する。
- 文面は `issues/001` の自動取り込み機能を含む内容であるため、001 の UI 注意事項と矛盾しないか確認する。

## 影響範囲

- `lib/calendar.dart`
- `lib/` 配下の新規画面ファイル
- `pubspec.yaml`
- `assets/` または `lib/` 配下の本文定義ファイル
- `test/widget/`

## 実装方針

1. ハンバーガーメニューに「その他」を追加する。
2. 既存のハンバーガーメニュー直下の「ライセンス」を削除し、「その他」画面へ統合する。
3. 「その他」画面を追加する。
   - 「利用規約」
   - 「プライバシーポリシー」
   - 「ライセンス」
4. 利用規約画面・プライバシーポリシー画面を追加する。
   - 長文表示に対応するためスクロール可能にする。
   - 本文はアプリ内に同梱する。
5. ライセンスは既存と同じ `showLicensePage` を「その他」画面から開く。
6. 001 の注意事項リンクから必要に応じて利用規約・プライバシーポリシーへ遷移できるようにする。

## エージェント編成

- manager: 計画管理、001 との文言整合、タスク更新、最終確認。
- developer: 画面・導線・Widget テスト実装。
- reviewer: 実装後レビュー、文言・導線・既存メニュー影響確認。

## 実装順序

1. 本文の配置方法を決定する。
   - 初期案: `assets/legal/term_of_service.txt` と `assets/legal/privacy_policy.txt` に配置し、`pubspec.yaml` に登録する。
2. Widget テストを追加する。
3. 「その他」画面と法務文書表示画面を実装する。
4. 既存メニューの「ライセンス」を「その他」配下へ移動する。
5. 001 の注釈リンクとの連携が必要な場合は導線を接続する。
6. `flutter test` と `flutter analyze` を実行する。
7. タスク一覧を更新し、実装内容とドキュメントの差異を確認する。

## 未確定事項

- 利用規約・プライバシーポリシー本文を assets として同梱するか、Dart 定数として保持するか。
  - 初期案: 変更差分と閲覧性を優先して assets とする。
- 001 の注釈リンクから「利用規約」「プライバシーポリシー」の両方へ直接遷移させるか、注意事項ダイアログ内に要約だけを表示するか。
  - 初期案: 注意事項ダイアログを表示し、必要に応じて「プライバシーポリシー」を開ける導線にする。
