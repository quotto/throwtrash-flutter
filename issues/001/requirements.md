# ゴミ出し予定検索クライアントの実装
## 概要

- "ゴミ出し予定の自動検索API"を利用して、入力した郵便番号または住所をもとにアプリ内にゴミ出し予定を取り込む AI取り込み機能
- APIのレスポンスを得るには分単位の時間を要することから、非同期処理での取り込みを行う。

## 入力インターフェース

- ユーザーに対して以下の画面から当機能の入力ダイアログを起動する
  - アプリ起動時
    - アプリ起動時の入力ダイアログは初回のみ表示する。初回の実行/キャンセルに関わらず、次回以降のアプリ起動では表示しない。
  - ゴミ出し予定一覧画面の最下部に配置した取り込みボタンタップ時
    - ボタン表記は `AI取り込み（β）` とする。

- 入力ダイアログは以下で構成される。
  - タイトル: AI取り込み（β）
  - 郵便番号または住所入力のテキストボックス
    - 50文字の入力制限を行う
  - 実行ボタン
    - タップすることでゴミ出し予定の自動検索APIへリクエストを送信する
    - テキストボックス未入力状態時は不活性とする
  - キャンセルボタン
    - ダイアログを閉じる
    - 一度タップすると以降はアプリ起動時にダイアログを起動しないように、内部のステータスを更新する。
  - 注釈テキスト:`留意事項を読み、詳細な住所を入力しないようにしてください`
    - 「留意事項」はタップ可能なリンクとし、タップで以下の注意事項を表示する。
       ```
        ・AIによる自動登録機能であるため誤りを含む可能性があります。\n・現在登録済みのデータは削除されます。\n・住所を入力する際は番地等の詳細は入力しないでください。町名や丁目など、自治体で定められたゴミ出し予定の判別に必要十分な粒度で入力してください（例: 東京都新宿区西新宿2丁目）。\n・入力された情報はアプリ提供者側で一切保存・流用しません。また当機能に利用するAIは入力データの学習を無効化していますが、万が一当機能へのデータ入力により何らかの損害が発生した場合でもアプリ提供者は一切の責任を負いかねますのでご了承ください。
       ```

## APIリクエストの実行フロー

[ゴミ出し予定検索API](openapi.yaml) の仕様に従い、以下の要件でリクエストを実行する。

- 入力テキストに対して「郵便番号」と「それ以外＝住所」のいずれかを判別する
  - 日本国内の郵便番号の正規表現に一致すれば郵便番号と判断する。なお「-」がある場合・ない場合両方で検知する
  - 郵便番号に一致しなければ住所情報として扱う
- 判別した情報を基にAPIリクエストを実行する。実行後の結果取得は非同期で得るものとして、「取り込みには数分かかる可能性がある」「結果はゴミ出し予定一覧画面を開いて確認する」旨のメッセージを表示してダイアログを閉じる。
- 取り込み完了または失敗のローカル通知は、アプリがフォアグラウンドにある場合だけでなく、バックグラウンドにある場合も表示する。
- 正常なレスポンスを受けた場合は
  - アプリ内の登録情報を全て削除し、APIからのレスポンス内容に従ってゴミ出し予定を登録する。また、リモート同期待ち状態とする。
  - スマートフォン上のローカル通知で取り込みが完了したことを通知する。通知表示はアプリを再度開くことを条件にしない。
  - 次にゴミ出し予定一覧を開いた際に取り込みが完了したメッセージを表示する。
    - 背景色は正常系とする。
    - このメッセージは取り込み処理直後のみ表示し、次回以降は表示しない。
  - メッセージは"ゴミ出し予定を取り込みました"とする。
  - ローカル通知の本文もアプリ内表示メッセージと同じ内容にする。
- エラーを示すレスポンスが得られた場合
  - スマートフォン上のローカル通知でエラー内容を通知する。通知表示はアプリを再度開くことを条件にしない。
  - 次にゴミ出し予定一覧を開いた際に画面下部にエラー内容を表示する。
    - 背景色は異常系とする。
    - このメッセージは取り込み処理直後のみ表示し、次回以降は表示しない。
    - メッセージはエラータイプに応じて以下の通りとする。
      `invalid_address`: 入力された住所に対応するゴミ出し予定を特定できませんでした。町名・丁目までのおおよその住所で再度お試しください。
      `invalid_postal_code`: 入力された郵便番号に対応するゴミ出し予定を特定できませんでした。住所での取り込みをお試しください。
      `unsupported_schedule`: 一部のゴミ出し予定を取り込めませんでした。取り込めなかった内容は手動で確認してください。
      `unknown`: ゴミ出し予定の取り込みに失敗しました。時間をおいて再度お試しください。
  - ローカル通知の本文もアプリ内表示メッセージと同じ内容にする。

## そのほか

- APIエンドポイントは`./json/{stage}/config.json` にて値を注入する。
- APIキーは`--dart-define`にてビルド時に値を付与する。
- この実現のためCI/CDパイプラインを修正する。
