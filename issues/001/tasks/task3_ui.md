# task3: 自動取り込み UI 実装

## 担当

developer

## 状態

完了

## 内容

- アプリ初回起動時に自動取り込みダイアログを表示する。
- ゴミ出し予定一覧画面最下部に取り込みボタンを追加する。
- ダイアログに入力欄、実行、キャンセル、注釈リンクを実装する。
- 実行直後に非同期取り込み開始メッセージを表示してダイアログを閉じる。
- 編集画面で取り込み完了・エラー内容を画面下部メッセージとして一度だけ表示する。

## テスト

- 空入力時に実行ボタンが不活性。
- 50 文字制限が効く。
- 実行・キャンセルで初回表示状態が更新される。
- 一覧画面からダイアログを開ける。
- 実行後に開始メッセージが表示される。
- 編集画面で保存済みメッセージが表示され、再表示されない。

## 完了条件

- 対象 Widget テストが通る。
- 既存のカレンダー・一覧・編集導線を壊していない。

## 実績

- 初回起動時の自動取り込みダイアログ表示を追加した。
- 実行・キャンセルどちらでも初回起動ダイアログの再表示を抑止する処理を追加した。
- 一覧画面の末尾に自動取り込みボタンを追加した。
- ダイアログの入力欄、50文字制限、空入力時の実行ボタン無効化、留意事項表示を追加した。
- 編集画面で取り込み完了・エラーの一度きりメッセージを表示する処理を追加した。
- 全 Widget テストで既存導線の回帰がないことを確認した。
