# task3: AI取り込み UI 実装

## 担当

developer

## 状態

完了

## 内容

- アプリ初回起動時に AI取り込みダイアログを表示する。
- ゴミ出し予定一覧画面最下部に `AI取り込み（β）` ボタンを追加する。
- ダイアログに入力欄、実行、キャンセル、注釈リンクを実装する。
- 実行直後に非同期取り込み開始メッセージを表示してダイアログを閉じる。
- ゴミ出し予定一覧画面で取り込み完了・エラー内容を画面下部メッセージとして一度だけ表示する。
- 正常系・異常系の背景色はアプリ全体の共通定義を利用する。

## テスト

- 空入力時に実行ボタンが不活性。
- 50 文字制限が効く。
- 実行・キャンセルで初回表示状態が更新される。
- 一覧画面からダイアログを開ける。
- 実行後に開始メッセージが表示される。
- ゴミ出し予定一覧画面で保存済みメッセージが表示され、再表示されない。
- 正常系メッセージと異常系メッセージで背景色が切り替わる。

## 完了条件

- 対象 Widget テストが通る。
- 既存のカレンダー・一覧・編集導線を壊していない。

## 実績

- 初回起動時の AI取り込みダイアログ表示を追加した。
- 実行・キャンセルどちらでも初回起動ダイアログの再表示を抑止する処理を追加した。
- 一覧画面の末尾に AI取り込みボタンを追加した。
- ダイアログの入力欄、50文字制限、空入力時の実行ボタン無効化、更新後の注釈テキストと留意事項表示を追加した。
- 注釈テキストを明示的な改行なしのインラインリンク表示に変更した。
- 取り込み完了・エラーの一度きりメッセージ表示先を、編集画面からゴミ出し予定一覧画面へ移した。

## 追加対応

- 成功時は正常系、失敗時は異常系の共通背景色で表示するようにした。
- 既存の成功/失敗 SnackBar 背景色の直指定を共通定義へ寄せた。
- 全 Widget テストで既存導線の回帰がないことを確認した。
