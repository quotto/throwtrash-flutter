# E2Eテストの実装

## 要件

1. E2Eテストを実装する。対象はiOSとする。
2. テストフレームワークとしてMaestroを利用する。
3. 実行環境はGitHub Actionsとして、ワークフローを作成する。
4. 実行トリガーはreleaseブランチへのプッシュとする。
5. GitHub Actions上の実行は、Maestro CLIを利用して行う。
6. テスト実行結果をレポートとしてGitHub Actionsのアーティファクトに保存する。保存期間は7日とする。
7. Codemagic の iOS Release Build は、プルリクエスト作成時ではなく `release` ブランチへの push で実行する。

## 完了条件

- 以下のシナリオがMaestroで実装されること。
  - アプリの基本動作
    1. アプリを起動して、現在月のカレンダーが表示されること。
    2. メニューから登録画面に遷移し、以下の内容でゴミ出し予定を登録する。
       - ゴミの種類: 燃えるゴミ
       - スケジュール1: 毎週月曜日
       - スケジュール2: 毎月1日
       - スケジュール3: 第2水曜日
    3. 登録完了後、カレンダーに登録したゴミ出し予定が反映されていること。
    4. 再度登録画面に遷移し、以下の内容でゴミ出し予定を登録する。
       - ゴミの種類: プラスチック
       - スケジュール1: 毎週水曜日
    5. 登録完了後、カレンダーに登録したゴミ出し予定が反映されていること。
  - 登録済みデータの編集
    1. アプリを起動して登録画面に遷移し、以下の内容でゴミ出し予定を編集する。
       - ゴミの種類: 燃えないゴミ
       - スケジュール1: 毎週火曜日
       - スケジュール2: 毎月2日
       - スケジュール3: 第3木曜日
    2. 編集完了後、カレンダーに編集したゴミ出し予定が反映されていること。
    3. メニューからゴミ出し予定一覧画面に遷移し、登録したゴミ出し予定が表示されていること。
    4. ゴミ出し予定一覧画面で登録したゴミ出し予定を選択し、以下の通りに編集する。
       - ゴミの種類: 資源ゴミ
    5. 編集完了後、カレンダーに編集したゴミ出し予定が反映されていること。
  - 登録済みデータの削除
    1. アプリを起動して登録画面に遷移し、以下の内容でゴミ出し予定を登録する。
       - ゴミの種類: 燃えるゴミ
       - スケジュール1: 毎週月曜日
       - スケジュール2: 第4水曜日
    2. 登録完了後、カレンダーに登録したゴミ出し予定が反映されていること。
    3. メニューからゴミ出し予定一覧画面に遷移し、登録したゴミ出し予定を選択して削除する。
    4. 削除完了後、カレンダーから削除したゴミ出し予定が消えていること。
  - コピー機能の動作
    1. アプリを起動して登録画面に遷移し、以下の内容でゴミ出し予定を登録する。
       - ゴミの種類: 燃えるゴミ
       - スケジュール1: 毎週月曜日
       - スケジュール2: 第4水曜日
    2. 登録完了後、カレンダーに登録したゴミ出し予定が反映されていること。
    3. メニューからゴミ出し予定一覧画面に遷移し、登録したゴミ出し予定を選択してコピーを実行し、以下の内容でコピーする。
       - ゴミの種類: 燃えないゴミ
       - スケジュール1: 毎週火曜日
       - スケジュール2: 第4木曜日
    4. コピー完了後、カレンダーにコピーしたゴミ出し予定が反映されていること。
- GitHub Actionsのワークフローが作成され、テストが実行されること。また、全てのシナリオが正常に終了し、テスト実行結果がアーティファクトとして保存されること。

## そのほか

- 検証は以下のステップで実施すること。
  - ローカル環境での実行: Maestro CLIを利用して、ローカル環境でテストシナリオが正常に実行されることを確認する。
  - GitHub Actionsでの実行: 一時的に開発ブランチpushをトリガーにして、GitHub Actions上でテストが正常に実行されることを確認する。
  - トリガー条件をreleaseブランチプッシュに変更する。テストは実行しない。
  - Codemagic の iOS Release Build が `release` ブランチ push をトリガーにする設定であることを確認する。
