# カレンダー日付セルのゴミ表示上限と詳細ダイアログ

## 背景

現在のカレンダー画面では、同じ日に複数のゴミが対象になると対象ゴミの名前をすべて日付セル内に表示する。対象数が多い日は表示行数が増え続けるため、日付セルの高さを超えて描画され、カレンダー全体のレイアウトが崩れる。

日付セル内の一覧性は維持しつつ、セルの表示量を制限し、すべての対象ゴミは日付セルタップ時の詳細ダイアログで確認できるようにする。

## 要件

1. カレンダーの日付セル内に表示するゴミ名は、同一日あたり最大3種類までとする。
2. 同一日の対象ゴミが4種類以上ある場合、日付セル内では先頭3種類のみを表示する。
3. 表示上限を超えた場合、日付セル内の下部に `...+{超過数}` を表示する。
   - 例: 対象ゴミが5種類の場合は3種類を表示し、`...+2` を表示する。
4. 日付セルをタップした場合、対象日のすべてのゴミ名を表示するダイアログを開く。
5. ダイアログはセル内で省略されたゴミも含め、対象日の全件を表示する。
6. ダイアログのタイトルには対象の年月日を `YYYY年MM月DD日` 形式で表示する。
7. 対象ゴミが0件の日付セルをタップした場合もダイアログを開き、本文に「出せるゴミはありません」と表示する。
8. 既存のカレンダー表示、月移動、リロード、ゴミ種別ごとの色、Semantics マーカーの挙動は維持する。
9. 実装に合わせて単体テストと Widget テストを追加・更新する。
10. 実装後は `flutter analyze` と関連テストを実行する。

## 完了条件

- 対象ゴミが3種類以下の日付セルでは、従来通り対象ゴミ名だけが表示されること。
- 対象ゴミが4種類以上の日付セルでは、セル内表示が3種類に制限され、超過数が `...+{超過数}` として表示されること。
- 超過表示によって日付セル外へゴミ名がはみ出さないこと。
- 対象ゴミがある日付セルをタップすると、対象日のすべてのゴミ名を含むダイアログが表示されること。
- ダイアログのタイトルに対象日が `YYYY年MM月DD日` 形式で表示されること。
- 対象ゴミがない日付セルをタップすると、「出せるゴミはありません」と表示するダイアログが表示されること。
- ダイアログを閉じられること。
- 既存のカレンダー Widget テストが更新後も成功すること。
- `flutter analyze` が成功すること。

## 対象外

- ゴミデータ取得ロジック、スケジュール計算ロジック、同期 API の変更。
- カレンダー月移動や PageView の構造変更。
- ゴミ種別の色定義変更。
- ダイアログから編集画面へ遷移する機能追加。
- 4種類目以降の並び順変更。

## 注意事項

- コメントを追加する場合は日本語で記載する。
- 実装は `analysis_options.yaml` と `flutter_lints` に従う。
- レイアウト崩れ対策が目的のため、セル内の表示上限は UI 側で行い、モデルの全件データは失わない。
- Widget テストでは、セル内には4件目以降が表示されないこと、ダイアログには全件が表示されること、空の日付では「出せるゴミはありません」が表示されることを分けて確認する。
