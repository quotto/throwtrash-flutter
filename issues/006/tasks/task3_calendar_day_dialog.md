# task3: 日付セルタップ時の全件ダイアログ実装

## 担当

developer

## 状態

- [x] 完了

## 作業内容

- 対象ゴミがある日付セルをタップ可能にする。
- 対象ゴミがない日付セルもタップ可能にする。
- タップ時に `showDialog` で対象日の詳細を表示する。
- ダイアログタイトルに対象年月日を `YYYY年MM月DD日` 形式で表示する。
- ダイアログにはセル内表示から省略されたゴミ名も含める。
- 対象日のゴミが0件の場合は「出せるゴミはありません」と表示する。
- ダイアログを閉じる操作を提供する。
- Widget テストから対象セルとダイアログを特定できる Key/Semantics を追加する。

## 完了条件

- 日付セルタップでダイアログが開く。
- ダイアログタイトルに対象年月日が `YYYY年MM月DD日` 形式で表示される。
- 対象ゴミがある日は、ダイアログに対象日の全ゴミ名が表示される。
- 対象ゴミがない日は、ダイアログに「出せるゴミはありません」と表示される。
- 閉じる操作でダイアログを閉じられる。

## 期待成果物

- `lib/calendar.dart` の修正。
- ダイアログ表示の Widget テストで利用可能な識別子。

## 実施結果

- 日付セルを `InkWell` でタップ可能にした。
- `_calendarCellDate` と `_formatDialogDate` を追加し、対象年月日を `YYYY年MM月DD日` 形式で表示するようにした。
- `_showTrashDialog` を追加し、対象ゴミがある日は全ゴミ名、ない日は「出せるゴミはありません」を表示するようにした。
- Widget テスト用に `calendar-day-{pageIndex}-{cellIndex}`、`calendar-day-dialog`、`calendar-day-dialog-close` の Key を追加した。
